# VEIL Product Philosophy & Specifications

## "Simple outside. Fast inside."

Traditional enterprise retrieval systems burden users with complex configuration: vector dimensions, similarity metrics, chunking strategies, and multi-step pipeline parameters.

VEIL eliminates artificial complexity:
1. **Ask Immediately**: Query the live internet without uploading files first (e.g., current versions, changelogs, research).
2. **Add Files Freely**: Upload PDFs, DOCX, Spreadsheets, JSON, Code, Images, or Archives with instant in-browser previews.
3. **Cross-Reference & Fact Check**: Automatically or explicitly compare documents, or verify claims in your files against live web sources.
4. **Understand with Evidence**: Every answer is grounded in retrieved passages with verified source badges and measured microsecond latency.

Behind the scenes, VEIL leverages the official Moss runtime to execute hybrid semantic search in under 10 milliseconds over both persistent local files and ephemeral web scrape sessions.

## Visual Identity & Aesthetic Principles
VEIL's design strictly follows the aesthetic of the reference image:
- **Tone**: Quiet, intelligent, private, technical.
- **Palette**: Deep black background (`#050505`), near-black surfaces (`#0D0D0D`, `#111111`), refined borders (`#262626`), and restrained warm gold accents (`#C9A45C`, `#E0B96E`).
- **Pillars Layout**: Three editorial feature cards replicating the reference image layout, highlighting the active grounded AI state with warm gold borders.
- **Unified File Viewer**: Clean modal viewer with tabbed previews for PDFs, formatted tables for spreadsheets, highlighted code, image inspection, and archive listings.
- **Micro-Interactions**: Subtle fade transitions, real latency counters, source filter pills, and transparent query activity indicators.
